# Aide-mémoire du terminal Linux

## Se déplacer

| Commande | Ce qu'elle fait                        | Exemple    |
| -------- | -------------------------------------- | ---------- |
| `pwd`    | Affiche le dossier où je suis          | `pwd`      |
| `cd`     | Change de dossier                      | `cd ~/dev` |
| 'cd . .' | Remonte au dossier parent              | 'cd . .'   |
| 'ls -a'  | Montre les fichiers cachés             | 'ls -a'    |
| 'ls -l'  | Liste détaillée (taille, date, droits) | 'ls -l'    |
| 'ls'     | Liste des fichiers du dossier          | 'ls'       |
| 'cd ~'   | Retourne dans mon dossier              | 'cd ~'     |

## Fichiers et dossiers

| Commande | Ce qu'elle fait                    | Exemple                   |
| -------- | ---------------------------------- | ------------------------- |
| `cp`     | Copie un fichier                   | `cp a.txt b.txt`          |
| 'cp -r'  | Copie ub dossier                   | 'cp -r projet projet2'    |
| 'mkdir'  | Crée un dossier                    | 'mkdir archives'          |
| 'chmod'  | Change les droits d'un fichier     | 'chmod a-w important.txt' |
| 'touch'  | Créeun fichier vide                | 'touch a.txt'             |
| 'echo'   | Affiche un texte                   | 'echo"Bonjour"'           |
| 'rm'     | Supprime un fichier                | 'rm a.txt'                |
| 'rm -r'  | Supprime un dossier et son contenu | 'rm -r achives'           |
| 'rmdir'  | Supprimer un dossier vide          | 'rmdir vide'              |
| 'mv'     | déplacer ou renomer                | 'mv a.txt logs/'          |
